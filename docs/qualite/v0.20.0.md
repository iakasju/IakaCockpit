## Contenu livré (L26)
Deux **feux macOS** (vert + jaune) à droite des onglets de la Table, pour un **mode focus** :
- **F1** — `ProjectTabs` : 2 pastilles rondes (verte = agrandir, jaune = restaurer, pas de rouge),
  feu à l'état courant atténué/désactivé mais visible, `title`/`aria-label` i18n ; la barre est
  **rendue même à 0 onglet** (les feux restent présents).
- **F2** — état `workFocus` (App) : le **vert masque le rail (App) + la worklist (WorkingView)** et
  agrandit la zone de travail (`.workpane` `flex:1`), en **gardant la colonne de widgets à droite**
  (`.wkright`) + les **onglets** + le **toggle Shell/Conversation** (`.convhead`). Le **jaune**
  rétablit les colonnes.
- **F3** — commande Rust `set_fullscreen(on)` (façade unique, `window.set_fullscreen`) : le **vert**
  passe l'app en **plein écran OS** (si pas déjà) ; le **jaune n'y touche pas** (AR-1 : sortie du
  fullscreen via le feu natif macOS).

## Arbitrage
