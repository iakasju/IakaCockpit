## 1. Périmètre de la version

Cette version mineure scelle deux ensembles de travaux depuis `v0.9.0-rc` (L10 complet) :

### L10b — correctifs post-recette (robustesse runner/transcript)
- **`escape_cwd`** aligné sur la vraie règle Claude Code (`[^A-Za-z0-9] → '-'`) + filet
  **`resolve_transcript`** (recherche du `<session_id>.jsonl` réel) — corrige un « chat muet »
  latent pour tout projet au chemin « sale » (`_`, espace, accent).
- **Téardown StrictMode** de `useRunnerViews` aligné sur `usePty` (le tailer survit au
  remontage, listener rebindé) — supprime une course implicite `start`/`stop`.
- **Retrait de la couture pipes morte** (`runner.rs`, `useRunner.ts`, `RunnerTerminal.tsx`,
  façade `runnerOpen/Write/Interrupt/Close`) débranchée en L10a.

### L11 — Teams & agents (définition de premier rang) + liaison projet↔team
- **Entité `Team`** de premier rang en config JSON non sensible (clé `teams`) : `id`, `name`,
  `vignetteTeam`, **coordinateur désigné**, `agents[]`. **Entité `Agent`** : persona
  (`name`, `royaume`, `roleIndex`) **+ runner + modèle + skills**.
- **Écran Settings `TeamsEditor`** : créer/éditer/supprimer une team, son roster, **régler
  runner + modèle + skills par agent**, désigner le coordinateur. 4 runners (`claude-code`
  exécutable + `ollama`/`litellm`/`codex` définissables).
- **Liaison `project_team:<id>`** + popup **`TeamPicker`** : défaut = dernière team / 1ʳᵉ fois
  = team n°1 ; Confirmer persiste ; Annuler ouvre avec la team par défaut sans persister ;
  pas de logique d'invalidation.
- **Conversation routée au coordinateur** ; **`@agent` borné à la team**.
- **De-hardcodage du runner** : `WorkingView` passe le runner+modèle du coordinateur (plus de
  `runnerKind="claude-code"` en dur) ; **`pty_runner_open`/`resolve_runner_spec` Rust
  inchangés** (scrub env, `validate_cwd`, allowlist, trust, `session_id` = strictement L10).
- **Exécution staged honnête** : coordinateur `claude-code` → terminal-source réel ; autre
  runner → **bannière** « défini, exécution non câblée », aucun spawn, aucun crash.
- **Seed** `project_team:iaka-demo` (idempotent) → la démo s'ouvre sans popup.

### Correctifs d'appoint
- **`a30bf29`** — conversation démo routée vers le **coordinateur résolu** (plus le littéral).
- **`50f410a`** — **V1** : `is_secret` rendu robuste au namespace utilisateur `project_team:`
